This repository contains comprehensive legal documentation for multiple business entities, including both for-profit and nonprofit structures in the United States and Sweden.

## Document Structure

Each entity has documents organized by jurisdiction and entity type:

```
[entity]/
├── us/
│   ├── for-profit/
│   │   ├── articles_of_incorporation.md      # Delaware corporation formation
│   │   ├── certificate_of_formation.md       # Delaware LLC formation
│   │   ├── secretary_of_state_registration.md # State registration details
│   │   ├── partnership_agreement.md          # Partnership agreement template
│   │   ├── form_ss4.md                       # IRS EIN application
│   │   ├── cp575_ein_assignment.md           # IRS EIN confirmation
│   │   └── form_147c_determination.md        # IRS tax classification letter
│   └── nonprofit/
│       ├── articles_of_incorporation_nonprofit.md  # 501(c)(3) formation
│       └── form_1023_exemption_application.md      # IRS tax-exempt application
└── swedish/
    ├── for-profit/
    │   ├── bolagsordning.md                  # Articles of association
    │   ├── stiftelseurkund.md                # Formation deed
    │   └── registreringsbevis.md             # Registration certificate
    └── nonprofit/
        └── stadgar_ideell_forening.md        # Nonprofit association bylaws
```

## Document Categories

### US For-Profit Documents

1. **Articles of Incorporation** - Corporate formation document for Delaware C-Corporation
2. **Certificate of Formation** - LLC formation document for Delaware
3. **Secretary of State Registration** - Official state registration details
4. **Partnership Agreement** - General partnership agreement template
5. **Form SS-4** - IRS Application for Employer Identification Number (EIN)
6. **CP 575** - IRS EIN Assignment Notice
7. **Form 147c** - IRS Determination Letter for tax classification

### US Nonprofit Documents

1. **Articles of Incorporation (Nonprofit)** - 501(c)(3) nonprofit formation
2. **Form 1023** - IRS Application for Recognition of Tax-Exempt Status

### Swedish For-Profit Documents

1. **Bolagsordning** - Articles of Association for Aktiebolag (AB)
2. **Stiftelseurkund** - Formation deed/certificate
3. **Registreringsbevis** - Official registration certificate from Bolagsverket

### Swedish Nonprofit Documents

1. **Stadgar för Ideell Förening** - Bylaws for nonprofit association

## Usage Notes

1. **Templates**: All documents are templates and require customization with:
   - Specific dates
   - Names of officers/directors
   - Addresses
   - Financial details
   - Signatures

2. **Placeholders**: Look for placeholders marked with:
   - `[To be provided]`
   - `[Name]`
   - `[Date]`
   - `[Amount]`
   - `[XXXXXX-XXXX]` (for ID numbers)

3. **Legal Review**: These documents should be reviewed by qualified legal counsel before use.

4. **Compliance**: Ensure compliance with current laws and regulations in respective jurisdictions.

## Filing Instructions

### United States
- **Delaware**: File with Delaware Division of Corporations
  - Website: corp.delaware.gov
  - Phone: (302) 739-3073
  
- **IRS**: Submit tax forms to Internal Revenue Service
  - EIN: Online at IRS.gov or fax/mail
  - Form 1023: Online via Pay.gov

### Sweden
- **Bolagsverket**: File with Swedish Companies Registration Office
  - Website: www.bolagsverket.se
  - Phone: 0771-670 670
